# TodoDeck: 의도 (2026-10-18 확정)

- **결과물:** 바탕화면에 놓이는 작은 할 일 기기. MusicDeck과 같은 디자인(라이트·무광 블랙 테마, 소리와 손맛)에, 화면 끝에 숨었다 나오는 기능도 같다.
- **적기:** 전역 단축키 ⌃/를 누르면 바로 튀어나와 입력칸에 커서가 간다. 적고 엔터를 치면 저장되고 다시 들어간다. (⌘/는 코드 편집기와 노션에서 써서 피했다.)
- **마감:** "보고서 금요일", "과제 10/25 18시"처럼 끝에 날짜를 붙여 적는다. 남은 시간은 D-3, 5시간, 지남으로 표시한다.
- **목록:** 마감이 가까운 순서로 정렬하고, 마감 없는 일은 아래에 둔다. 체크하면 딸깍 소리와 함께 사라진다.
- **사용자·목적:** 본인 혼자 매일 쓰는 도구. 노션을 여는 게 번거로워서 만든다. Claude가 직접 만든다.
- **성공 기준:** 떠오르면 3초 안에 적고 돌아갈 수 있고, 다가오는 마감을 놓치지 않는다.
- **범위 밖:** 노션 연동, 여러 기기 동기화, 긴 메모, 반복 일정, 알림, MusicDeck과 하나로 합치기.
